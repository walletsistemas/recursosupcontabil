# Recursos UP Contábil

Guias de referência para construir, em outros projetos, funções que já existem no Sistema Contábil Plus.

| Guia | O que tem |
|---|---|
| [Tarefas, Estudos e E-mail](guia-tarefas-estudos-email/README.md) | Fotos das telas, stack e bibliotecas, regras de negócio, modelo de dados, API, trechos de código, visual, testes e armadilhas conhecidas — separado por pastas. |

Cada guia fica numa pasta própria, com as fotos dentro (`imagens/`). As fotos foram tiradas numa
base de teste, com nomes de pessoas e empresas trocados por nomes fictícios.
